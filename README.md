# ICAP Transport Inc.

Website for **ICAP Transport Inc.** — a North American trucking and logistics company.

Live product pages: Home, Services (14 modes), Tracking, Quote, About, Contact.

## Stack

React 19 · TypeScript · Vite · TanStack Start · Tailwind CSS v4

## Local

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check
